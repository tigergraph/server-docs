=== Download the TigerGraph Spark Connector

The connector is published to Maven Central separately for Scala 2.12 and Scala 2.13:

* https://central.sonatype.com/artifact/com.tigergraph/tigergraph-spark-connector_2.12/overview[`com.tigergraph:tigergraph-spark-connector_2.12`]
* https://central.sonatype.com/artifact/com.tigergraph/tigergraph-spark-connector_2.13/overview[`com.tigergraph:tigergraph-spark-connector_2.13`]

The Scala version suffix must match the Scala version of your Spark installation.
The connector JAR, `tigergraph-spark-connector_<scala_version>-<version>.jar`, includes all dependencies.

NOTE: Connector versions 0.2.4 and earlier are published without a Scala suffix, as `com.tigergraph:tigergraph-spark-connector`.

To use the TigerGraph Spark connector in a Spark shell:

.use the `--jars` option:
[console]
----
spark-shell --jars tigergraph-spark-connector_<scala_version>-<version>.jar
----

[NOTE]
====
If you want to include the TigerGraph Spark Connector in your Spark installation, add the connector `JAR` to Spark's `jars` folder.
====

=== Configure Logging

We highly recommend setting the log level to `info` to monitor the execution. There are two methods to enable logging for the connector.

==== Connector Default Logger
The connector has a built-in logger based on _java.util.logging_.
To activate it, set the option `log.level` to 2, which enables info-level logging.

Please refer to <<Common Options>> to learn more about `log.level` and `log.file` options.

==== Spark Logger
Configure Spark Log4j by `$SPARK_HOME/conf/log4j2.properties` as follows, or other SLF4j bindings if any:

[console]
----
logger.tg.name = com.tigergraph
logger.tg.level = info
----
